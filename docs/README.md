# Math formulas
## Square

### Area
Calculates the area of a square using formula: S = a²

#### Params
- a (int / float): The side of the square

#### Result
- area (int / float): The area of the square

#### Example
```python
>> area(5)
25

>> area(10)
100
```

### Perimeter
Calculates the perimeter of a square using formula: P = 4a

#### Params
- a (int / float): The side of the square

#### Result
- perimeter (int / float): The perimeter of the square

#### Example
```python
>> perimeter(5)
20

>> perimeter(10)
40
```

## Rectangle

### Area
Calculates the area of a rectangle using formula: S = ab

#### Params
- a (int / float): The width of the rectangle
- b (int / float): The height of the rectangle

#### Result
- area (int / float): The area of the rectangle

#### Example    
```python
>> area(5, 10)
50

>> area(10, 20)
200
```

### Perimeter
Calculates the perimeter of a rectangle using formula: P = 2(a + b)

#### Params
- a (int / float): The width of the rectangle
- b (int / float): The height of the rectangle

#### Result
- perimeter (int / float): The perimeter of the rectangle

#### Example
```python
>> perimeter(5, 10)
30

>> perimeter(10, 20)
60
```

## Triangle

### Area
Calculates the area of a triangle using formula: S = 1/2 ah

#### Params
- a (int / float): The base of the triangle
- h (int / float): The height of the triangle tough the base

#### Result
- area (int / float): The area of the triangle

#### Example
```python
>> area(5, 10)
25

>> area(10, 20)
100
```

### Perimeter
Calculates the perimeter of a triangle using formula: P = a + b + c

#### Params
- a (int / float): The first side of the triangle
- b (int / float): The second side of the triangle
- c (int / float): The third side of the triangle

#### Result
- perimeter (int / float): The perimeter of the triangle

#### Example
```python
>> perimeter(5, 10, 15)
40

>> perimeter(10, 20, 30)
60
```
